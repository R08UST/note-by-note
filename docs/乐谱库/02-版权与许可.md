# 02 版权与许可

> 站点是所有者个人使用的练琴网站。所有者 2026-11-26 表示不在意版权问题，流行曲照收。即便如此，每份谱子仍然记下可核对的来源和许可，方便日后查找和下架。对外的正式记录在仓库的 `THIRD_PARTY.md`。

## 原则

- **古典曲目**：作曲已进入公有领域，编配或排版本身也必须是 CC0 / PDM / CC BY / CC BY-SA。非商用（NC）和许可不明的一律不收。
- **流行、动漫、游戏曲（所有者 2026-11-26 决定收录）**：MuseScore 编配者标的 CC0 只管编配本身，管不到曲子。这些曲子的**作曲仍受版权保护**，卡片上要写清楚：
  - `license`：`编配 CC0-1.0，作曲仍受版权保护`（或 `编配 PDM-1.0，…`）
  - `attribution`：开头写"作曲仍受版权保护，不属于公有领域。"，再写编配者和原谱链接
  - 应用内「设置 → 关于 / 版权」也有一条 Vivace 的说明
- **版权方要求下架**：照 01 第三节的步骤删掉对应卡片和文件，然后重新部署。

## 各许可要怎么做

| 许可 | 要求 | 卡片里的写法 |
|---|---|---|
| CC0-1.0、PDM-1.0、Public Domain | 无署名要求，仍然列出出处方便核对 | 写来源 |
| CC BY 2.5 / 3.0 / 4.0 | 复制时必须保留作者、来源和许可 | `attribution` 写全，卡片会显示「署名」 |
| CC BY-SA 2.5 / 3.0 / 4.0 | 同上；改编后的 MusicXML 也要用同样的许可 | 同上 |

## 需要留意的个别曲子

- **Luv Letter（DJ Okawari，`noc-dj-okawari-luv-letter`）**：用户自己提供的 MuseScore 导出版，卡片写的是 `CC0-1.0`。但这首曲子的作曲仍受版权保护，严格来说应改成 `编配 CC0-1.0，作曲仍受版权保护`。所有者表示不在意版权，所以保持原样。
- **Kevin MacLeod 的曲子**：作曲本身是 CC BY，卡片按"作曲受版权保护"写，不算错，但从严了。
- **Chopin First Editions（28 首）**：CC BY 4.0，卡片里已写"复制时须保留作曲家、来源与许可"。
