# 00 乐谱库总览

> Note by Note（钢琴练习站）曲库的来源记录。日期：2026-11-26（Asia/Shanghai）。数字以 `public/pieces/manifest.json` 为准；维护文档目录里有导出的数据快照和导出脚本。

## 曲库在仓库里的位置

| 位置 | 内容 |
|---|---|
| `public/pieces/manifest.json` | 应用读取的总清单。由 `npm run smoke-library` 生成，**不要手改** |
| `public/pieces/*.musicxml`、`*.mxl` | 谱子文件本身 |
| `public/pieces/noctave.json` | Noctave 书架的条目（`noc-` 前缀） |
| `public/pieces/pdmx.json` | Vivace / PDMX 书架的条目（`pdmx-` 前缀） |
| `public/pieces/mutopia.json`、`mutopia-skipped.json` | Mutopia 精选书架（`mutopia-`），以及转换失败没收的清单 |
| `public/pieces/etudes.json`、`method.json` | 练习曲（`etude-`）和教材（`method-`）书架 |
| `src/score/pieces.ts` | 3 首内置示例（`?raw` 导入，不在 manifest 里） |
| `src/score/composers.ts` | 作曲家名的归并和中文名 |
| `THIRD_PARTY.md` | 每批谱子的来源、许可和没收的原因（对外的正式记录） |

`manifest.json` 里的 `os-` 和 `mut-` 两组没有单独的书架文件，smoke-library 在没有外部候选列表时直接保留 manifest 里的现有条目。

### 各库的上游关系

```text
MuseScore 用户上传（自选 CC0 / 公有领域）
   └─ PDMX 语料库（Zenodo, 25 万份 MusicXML, 数据集本身 CC BY 4.0）
        ├─ Vivace Music（再排版、提供 .mxl） ──► pdmx- 书架
        ├─ Noctave（部分曲目）             ──► noc- 书架
        └─ 直接下载 mxl.tar.gz             ──► pdmx- 书架（2026-11-26 起）
Mutopia Project（LilyPond 源）
   ├─ 直接用其 MIDI 转换                   ──► mutopia- / etude- / method- 书架
   └─ Noctave（大量曲目）                  ──► noc- 书架
Chopin First Editions（NIFC, Humdrum 编码, CC BY 4.0）
   └─ Vivace Music 转为 MusicXML          ──► pdmx- 书架（肖邦 28 首）
opensongs-json                             ──► os- 书架
```

## 没有用的库，以及原因

| 库 | 原因 |
|---|---|
| KernScores / Humdrum 各合集 | Vivace 页面写"licence varies by collection"，没有统一许可（如完整的月光奏鸣曲、艺人、枫叶拉格） |
| ASAP 数据集 | CC BY-NC-SA 4.0，只许非商用（如钟、悲伤练习曲、拉威尔帕凡舞曲） |
| Vivace 自己的简易改编（`vivace-simplified`） | 页面不写许可 |
| MuseScore 官网直接下载 | 需要登录，单首许可要逐页核对；改为走 PDMX |
| Mikrokosmos、小汤大汤、柯达伊 333、波佐利、拜厄（有版权或找不到可用版本） | 见 `THIRD_PARTY.md` |

## 数据快照（不在仓库里，在维护文档目录 `Documents/Software/维护文档/NoteByNote-乐谱库-维护文档/data/`）

| 文件 | 内容 |
|---|---|
| `曲库清单.csv` | 每首一行：id、书架、上游、级别、标题、中文标题、作曲家、许可、是否受版权保护、小节数、调号、拍号、单双手、文件、来源链接、署名。带 BOM，可直接用 Excel 打开 |

| `上游目录快照/vivace-songs-20261126.json` | Vivace 全目录（4228 首，含来源与许可字段），来自 `https://vivace-music.org/library/data/songs.json` |

PDMX 的 `PDMX.csv`（225 MB）和 `mxl.tar.gz`（1.9 GB）太大，没有放进来，需要时从 Zenodo 重新下载（见 01）。
